# Pilot readiness — deferred

**Status: Not ready; no pilot is proposed by the current prototype plan.** This file is retained as a future checklist only. It does not authorize use of government records, farmer data, live imagery, production decisions or external services.

The current deliverable is the local educational prototype in [`PROTOTYPE_SCOPE.md`](PROTOTYPE_SCOPE.md). Synthetic scenarios, unit tests and a successful demo do not establish field accuracy or pilot safety.

Revisit pilot planning only after the team has:

- a named sponsor and data steward with written authorization for each data source;
- a privacy, security, retention and deletion review;
- representative, permissioned historical data and a pre-registered evaluation plan;
- trained human reviewers and an independently reviewed decision protocol;
- documented failure handling, escalation and rollback;
- accessibility and Marathi language review with intended users;
- evidence that the system remains advisory and cannot alter compensation/payment systems.

Until then, X-05 and every live-pilot task remain deferred. Do not use the earlier four-week roadmap as an active schedule.
